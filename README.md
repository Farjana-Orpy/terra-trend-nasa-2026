# Terra Trend

**Explore environmental patterns through data and visual analysis.**

Terra Trend is an interactive web project for exploring environmental indicators, comparing locations, and examining trends over time.

## Features

- **Explore locations** — Choose places or coordinates to study.
- **View indicators** — Examine temperature, precipitation, humidity, wind, and solar radiation.
- **Compare trends** — Visualise annual changes and compare locations.
- **Export results** — Download analysis data for further review.
- **Switch data modes** — Explore illustrative offline examples or request NASA POWER data.

## Technology

HTML · CSS · JavaScript · NASA POWER API
