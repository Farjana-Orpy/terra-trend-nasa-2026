TERRATREND — CLOUDFLARE PAGES GIT DEPLOYMENT

Repository: https://github.com/Farjana-Orpy/terra-trend-nasa-2026
Cloudflare Pages project name: terratrend
Production branch: main

Use Cloudflare Pages Git integration. Do not use the Workers Builds setup form and do not use a static drag-and-drop upload because the project includes a Pages Function.

Build settings:
- Framework preset: None
- Build command: sh build.sh
- Build output directory: dist
- Root directory: leave blank
- Environment variables: none required

Cloudflare dashboard path:
Workers & Pages → Create application → Pages → Connect to Git → select this repository → configure the settings above → Save and Deploy.

The build script copies public files to dist/ and creates dist/_routes.json. The Pages Function stays at functions/api/power.js in the repository root.
